# 12. OTP SYSTEM

This is one of the most important features.

The Admin generates an OTP for each exam.

Example:

```text
Exam:
React Native Fundamentals

OTP:
583921
```

Student cannot start the exam without the correct OTP.

Flow:

```text
Exam Details
      ↓
Start Exam
      ↓
OTP Verification
      ↓
Enter OTP
      ↓
Backend validates OTP
      ↓
Correct
      ↓
Exam starts
```

Wrong OTP:

```text
Invalid OTP
```

Do not reveal the correct OTP.

OTP should be securely stored.

Prefer storing a hashed OTP instead of plain OTP where practical.

OTP should have an expiration/validity rule.

Admin can regenerate OTP.

Previous OTP should become invalid when a new OTP is generated.

# 52. IMPORTANT BUSINESS RULES

Implement these rules exactly:

```text
1. One email = one account.

2. Blocked student cannot use the application.

3. Only Admin can create exams.

4. Only Admin can edit/delete exams.

5. Only Admin can add/edit/delete questions.

6. Only Admin can generate OTP.

7. Student cannot start before exam start time.

8. Student cannot start without valid OTP.

9. Student can attempt each exam only once.

10. Each exam contains 50 MCQs by default.

11. Exam has a limited duration.

12. Time expiry automatically submits the attempt.

13. Student cannot continue after timeout.

14. Student cannot immediately see result.

15. Admin controls result release.

16. Student sees result only after release.

17. Leaderboard is hidden until result release.

18. Score is calculated by backend.

19. Correct answers are never sent to student before result evaluation.

20. Admin can block/delete students.
```
